# Project brain

Start here to recover context, choose the next step, or capture an idea.
This vault explains the repository; it does not replace code, tests, or the factory board.

## Understand

## Work

- [[Plans/Work-plan|Principal work plan (local only)]] — consult before planning or implementation; not completion status.
- [[Roadmap]] — concrete next actions, not an invented feature backlog.
- [[Factory]] — where execution state and canonical instructions live.
- [[Inbox]] — capture without interrupting the current task.
- [[Daily/2026-10-28|Initial handoff]] — a dated snapshot, not live status.

## Keep it useful

1. Capture one thought in [[Inbox]] or today's daily note.
2. Link it to an existing project note; use a decision note for a real tradeoff.
3. After work, record evidence and one next action. Weekly, process the inbox and
   recheck stale facts against source files instead of duplicating implementation state.
