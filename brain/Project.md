# Real-estate coursework project

The repository is a real-estate project for the final assignment in Programming IV,
as stated in the [root README](../README.md).

## What exists

- An Express/CommonJS API starter with layered folders and built-in Node tests.
- An independent Python standard-library WSGI starter with unittest coverage.
- A Codex file-based software factory for turning an explicit feature into reviewed work.
- This vault, for human context and decisions rather than automation state.
